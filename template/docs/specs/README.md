# Spec nghiệp vụ

Mỗi quy trình một file `NNN-ten-quy-trinh.md`, tạo bằng `/business-flow`. Chỉ code khi spec ở trạng thái "Đã duyệt".
Nghiệp vụ thay đổi sau khi duyệt: sửa spec trước, code sau. Mỗi BR-xx phải có test dẫn đúng mã đó.

`001-phieu-de-nghi-mua-hang.md` là spec mẫu, khớp với module `apps/api/src/modules/purchase-requests/`. Xóa cả hai khi
dự án thật đã có module đầu tiên của mình.
